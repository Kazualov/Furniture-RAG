# **Инструкция по запуску поискового движка (Quick Start Guide)**

### **0\. Загрузка данных и настройка .env**

1. Скачайте все необходимые датасеты и эмбеддинги с [Яндекс.Диска](https://disk.yandex.ru/d/x-aCaPN23Cf2hQ) (там лежит всё, кроме полных FP32 эмбеддингов, которые весят много). Разместите их локально согласно структуре папок (/data и /embeddings).  
2. В корне проекта создайте или обновите файл .env (можно скопировать из src/database/env.example).  
3. Для быстрых тестов и проверки работоспособности (на микро-данных) укажите следующие пути:  
   Code snippet  
* PARQUET\_PATH=./embeddings/office\_products\_micro.parquet  
* VECTORS\_PATH=./data/vectors\_micro.parquet


*(Для финальных бенчмарков меняем пути на \_full версии).*

### **Шаг 1\. Подготовка Parquet-файла векторов**

Если вы обновили или заново скачали эмбеддинги и их нужно перевести в единый .parquet формат для быстрой загрузки в векторное хранилище, запустите:

Bash

* python src/database/prepare\_vectors\_parquet.py


  ### **Шаг 2\. Запуск инфраструктуры (Базы данных)**

Убедитесь, что у вас запущен Docker Desktop. Поднимаем контейнеры с PostgreSQL и Qdrant в фоновом режиме:

Bash

* docker compose up \-d


*Примечание: Если запускаете из папки src/database/, используйте команду docker compose up \-d там.*

### **Шаг 3\. Первичная загрузка данных в БД**

Скрипты берут пути к файлам напрямую из вашего .env.

Загружаем текстовые метаданные и строим Full-Text Search индекс в PostgreSQL:

* python \-m src.database.load\_postgres

Загружаем сырые векторы в Qdrant:

* python \-m src.database.load\_qdrant

**Шаг 4\. Конфигурация коллекции и создание HNSW индексов**

Настраиваем параметры графа в Qdrant для ускорения поиска (этот шаг обязателен перед замером финальной латентности):

Bash

* python \-m src.indexing.configure\_qdrant


  ### **Шаг 5\. Запуск поискового движка (API)**

Запускаем наше основное FastAPI приложение оркестрации:

Bash

* python \-m src.search.main


Готово\! Наше API поднялось.

* Проверить интерактивную документацию (Swagger) и подергать эндпоинты можно тут: **http://localhost:8000/docs**
